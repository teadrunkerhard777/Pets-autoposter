# Проверка источников

Проверка: 08.09.2026.

| Источник | Роль | Результат | Решение |
|---|---|---|---|
| ASPCA News | новости благополучия животных | `https://www.aspca.org/rss.xml` возвращает RSS XML | включён |
| Blue Cross News | забота о питомцах и помощь животным | `https://www.bluecross.org.uk/rss.xml` возвращает RSS XML | включён |
| Petstory | русскоязычные статьи о питомцах | карточки страницы не содержат даты публикации | не зарегистрирован |
| PetMD | ветеринарные справочные RSS | документированные URL сейчас возвращают HTML вместо RSS | не зарегистрирован |

Для каждого нового источника обязательны проверка прямых ссылок, timezone-aware даты, доступности без CAPTCHA и отдельный тестовый fixture. Никакие блокировки, CAPTCHA или login-wall не обходятся.
