# Project covers

These square PNG covers are project-owned presentation assets generated for
the Pets Autoposter on 2026-09-12 with OpenAI's built-in ImageGen.

The shared direction is a warm modern editorial illustration, friendly but not
childish, with generous negative space, no text, no logo, and no watermark.
Each file represents a stable visual role rather than a specific reported
event:

- `news.png`: mixed domestic pets and general news;
- `safety.png`: a cat and dog protected from household hazards;
- `care.png`: calm everyday feeding, walking, and grooming;
- `welfare.png`: humane adoption and shelter support;
- `cat_fact.png`: indoor cat enrichment and behaviour.

Source images remain preferred. These files are used only when a source image
is absent or unsuitable, and must never be described as documentary imagery.
