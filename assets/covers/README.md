# Project covers

These square PNG covers are project-owned presentation assets generated for
the Pets Autoposter on 2026-09-12 with OpenAI's built-in ImageGen.

The shared direction is a warm modern editorial illustration, friendly but not
childish, with generous negative space, no text, no logo, and no watermark.
Each pair represents a stable visual role rather than a specific reported
event. The autoposter makes a deterministic choice from the pair using the
article URL, so the same article keeps the same cover across retries:

- `news.png`, `news_2.png`: mixed domestic pets and general news;
- `safety.png`, `safety_2.png`: prevention of household risks;
- `care.png`, `care_2.png`: calm everyday care and grooming;
- `welfare.png`, `welfare_2.png`: humane adoption and shelter support;
- `cat_fact.png`, `cat_fact_2.png`: indoor cat enrichment and behaviour.

Source images remain preferred. These files are used only when a source image
is absent or unsuitable, and must never be described as documentary imagery.
